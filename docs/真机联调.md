# 真机联调

后端 `AirDogsApi` 已经在 `0.0.0.0:8080` 监听，客户端有三种连法。

## 方式 A：USB + adb reverse（推荐，不用改网络）

手机插上 USB、打开「开发者选项 → USB 调试」，然后在项目根目录跑一条命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\tool\dev_link.ps1
```

脚本会依次做：找设备 → `adb reverse` → 装 APK → 启动 App。
没连手机时会打印检查清单并退出，不会动模拟器。

手动等价命令：

```powershell
adb devices                       # 确认能看到你的手机
adb reverse tcp:8080 tcp:8080     # 手机的 8080 转发到电脑的 8080
adb install -r build\app\outputs\flutter-apk\app-debug.apk
```

App 登录页点 **「USB 真机 127.0.0.1:8080」** 快捷填充，再输账号密码。

- 优点：不受 Wi-Fi、防火墙、IP 变化影响；换电脑也不用改配置。
- 注意：`adb reverse` 在拔掉 USB 或重启 adb 后失效，重插后重新执行一次。

## 方式 B：同一 Wi-Fi + 局域网 IP

```powershell
ipconfig | findstr IPv4           # 找到电脑的局域网地址，例如 192.168.31.27
```

App 登录页填 `192.168.31.27:8080`。

**必须先放行防火墙端口**（管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "AirDogsApi 8080" -Direction Inbound `
  -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private
```

手机和电脑要在同一个 Wi-Fi，且路由器没开「AP 隔离」。

## 方式 C：模拟器

登录页点 **「模拟器 10.0.2.2:8080」**——`10.0.2.2` 是 Android 模拟器访问宿主机的固定地址。

## 排查

| 现象 | 原因 |
|---|---|
| 登录转圈后提示「连接服务器失败」 | 地址填错 / 后端没启动 / 防火墙拦了 |
| 提示「登录已过期」 | token 失效，重新登录即可 |
| 能登录但列表是空的 | 后端启动时是空库；先在 App 里建一条，或确认登录的是 `zyy` / `momo` |
| 图片不显示 | 图片是 `GET /api/files/{id}`，确认手机能访问同一个 baseUrl |
| 拔了 USB 就打不开 | `adb reverse` 失效，重新执行；或改用方式 B |

# Windows 桌面版

```powershell
flutter build windows --debug
build\windows\x64\runner\Debug\airdog_mobile.exe
```

窗口固定 430×900（手机比例），标题「小窝」，桌面版登录页自动填 `127.0.0.1:8080`。

## 坑：没有开发者模式时构建失败

```
Building with plugins requires symlink support.
Please enable Developer Mode in your system settings.
```

Flutter 会在 `windows/flutter/ephemeral/.plugin_symlinks/` 下给每个插件建**符号链接**，
而创建符号链接需要「开发者模式」或管理员权限。两条路：

**A. 打开开发者模式**（推荐，一劳永逸）
设置 → 系统 → 开发者选项 → 开发人员模式。或管理员 PowerShell：

```powershell
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\AppModelUnlock" /t REG_DWORD /f /v AllowDevelopmentWithoutDevLicense /d 1
```

**B. 用目录联接（junction）绕过**

普通用户也有权限创建目录联接。先 `flutter pub get`，再把 `.flutter-plugins-dependencies`
里 `windows` 段的每个插件联接到 `.plugin_symlinks/<名字>`：

```powershell
$links = "windows\flutter\ephemeral\.plugin_symlinks"
$cache = "$env:LOCALAPPDATA\Pub\Cache\hosted\pub.flutter-io.cn"
New-Item -ItemType Junction -Path "$links\sqlite3_flutter_libs" -Target "$cache\sqlite3_flutter_libs-0.5.42"
# 其余插件同理
```

清空 `windows/` 或升级插件后要重做。本项目当前就是用这种方式构建的。

## 其他

- 桌面版不显示「模拟器 10.0.2.2」快捷填充，只显示「本机 127.0.0.1」。
- 登录页密码框支持回车提交（Windows 上点按钮偶尔抢不到焦点，回车更稳）。
- 截图时 PowerShell 要 `SetProcessDPIAware()`，否则 150% 缩放下只能截到左上角一块。
