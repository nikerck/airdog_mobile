# 代码导读

给第一次读这个项目的人（包括三个月后的自己）。

## 一、30 秒看懂

```
main.dart ──► App(主题 + 路由) ──► ShellPage(三个 tab)
                                       │
              ┌────────────────────────┼───────────────────────┐
              ▼                        ▼                       ▼
          HomePage                 AlbumPage               MePage
              │
              ├── 模块卡片 ──► /todo  /period  /wish（路由页）
              │
              └── 每个模块三层：ui/ → data/ → core/api + core/sync
```

一句话：**一个 Flutter 壳 + 若干模块；模块之间互不认识，只通过 `AppModule` 契约注册；数据一律先落本地 SQLite，再把变更同步到自己的后端。**

## 二、目录职责

| 目录 | 干什么 | 改这里会影响 |
|---|---|---|
| `lib/app/` | 主题、路由、根 Widget | 全局外观、页面跳转 |
| `lib/core/db/` | 表结构 + 迁移 | 所有数据 |
| `lib/core/api/` | 每个接口一个文件 + DTO | 和后端的契约 |
| `lib/core/sync/` | 同步引擎（拉/写/轮询） | 数据一致性 |
| `lib/core/auth/` | 登录态、token 存取 | 整个 App 的进出口 |
| `lib/core/network/` | Dio 配置、错误翻译 | 所有请求 |
| `lib/modules/` | 业务模块（待办/经期/愿望） | 功能 |
| `lib/features/` | 壳里的页面（首页/相册/我的/登录） | 界面 |
| `lib/shared/widgets/` | 跨模块复用的小组件 | 局部 |

## 三、三个关键概念

### 1. 模块契约（`modules/module.dart`）

外壳只认 `AppModule`，不认识任何具体模块。新增一个模块：

```dart
class NoteModule extends AppModule {
  String get id => 'note';
  String get name => '笔记';
  String get tagline => '随手记';
  IconData get icon => Icons.edit_note;
  String get route => '/note';
  int get order => 3;
  SpaceKind get space => SpaceKind.personal;   // personal 不同步给对方
  Color accent(ThemeData t) => ...;
  Color accentSoft(ThemeData t) => ...;
  Widget buildPage(BuildContext context) => const NotePage();
}
```

然后在 `modules/registry.dart` 加一行 `appModules = [..., NoteModule()]`。

首页宫格、路由表、我的页模块开关**都会自动带上它**，不用改别的地方。

### 2. Provider 图（`core/api/api_providers.dart`）

```
authProvider（baseUrl + token + userId）
  ├─► apiDioProvider ─┬─► syncServiceProvider ─┬─► startupSyncProvider（启动拉一次）
  │                   │                        └─► syncPollerProvider（前台 30 秒）
  │                   └─► spacesProvider ──► membersById ──► meMember / partners
  └─► currentUserIdProvider
```

规矩：

- 页面只 watch **最末端**的 provider（比如 `todosProvider`），不直接碰 Dio
- 想加「派生数据」（比如首页统计），写在 `features/home/dashboard.dart`，不要塞进页面 build 里

### 3. 数据流：本地是缓存，服务端是权威

写：`UI → Repository → SyncService → 接口成功 → 写回本地 → Stream 刷新 UI`

读：`UI ← Stream ← 本地 SQLite`（离线也能看）

细节见 [同步机制.md](同步机制.md)。

## 四、常见改动：改哪里

| 想做的事 | 改这些文件 |
|---|---|
| 待办加一个字段 | `core/db/tables.dart` → `app_database.dart`（版本 +1、写 migration）→ 重新 `build_runner` → `dto.dart` → `sync_service.dart` 的 upsert → UI |
| 加一个模块 | `modules/xxx/` 三个文件 + `registry.dart` 一行 |
| 换主题色 | `app/theme/app_theme.dart` 的 `accentColors` |
| 加一个接口 | `core/api/xxx_api.dart` + DTO + 在对应 Repository 里调用 |
| 改同步时机 | `core/sync/sync_poller.dart`（间隔）、`features/shell/shell_page.dart`（启动） |
| 改首页布局 | `features/home/home_page.dart`（样式）+ `dashboard.dart`（数据） |

## 六、约定与坑

**约定**

- 所有金额用整数「分」，展示才 `/100`（`wish_stats.dart` 里有格式化/解析函数）
- 所有时间存 `DateTime`，JSON 里是毫秒时间戳
- 删除一律软删（置 `deletedAt`），否则别的设备不知道
- 网络错误统一 `ApiException`，页面只用 `message`
- 页面里的写操作包一层 `runGuarded(...)`，失败自动弹 SnackBar

**坑**

- `api_client` 里 `validateStatus: status < 500`：4xx 不抛异常，**每个接口方法都必须 `ApiClient.unwrap(res)`**，否则 401/403/409 会被当成成功
- 带输入框的弹窗不要用 `AlertDialog`（安卓上会被键盘挤到看不见按钮），统一用 `showModalBottomSheet`，参考 `money_input.dart`
- `///` 文件头注释后面要跟 `library;`，否则 lint 报 dangling doc comment
- 生成文件 `app_database.g.dart` 不要手改，改完表结构跑 `flutter pub run build_runner build`
